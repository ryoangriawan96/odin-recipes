# Odin Recipes: Botanical Blends

## About The Project

This project is a fundamental HTML website built as part of The Odin Project's Foundations curriculum. It serves as a structured digital catalog designed to showcase high-resolution, isolated botanical assets and precise product copywriting for traditional Indonesian herbal blends.

### Featured Recipes

- **Moringa Oleifera Herbal Tea**
- **Turmeric Tamarind Elixir**
- **Centella Asiatica Extract**

## Skills Demonstrated

- Semantic HTML5 structuring (headings, paragraphs, lists, emphasis tags)
- Absolute and relative pathways for links and image rendering
- Version control best practices using Git (atomic commits, imperative messaging)
- Deployment via GitHub Pages
